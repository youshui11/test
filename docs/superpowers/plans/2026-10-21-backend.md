# 资料查询助手后端 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** 按已确认设计完成可运行后端和现有前端对接。
**Architecture:** backend 包隔离配置、数据库、路由和模型服务；前端同源 HTTP + SSE。
**Tech Stack:** FastAPI, async SQLAlchemy, PostgreSQL/pgvector, Agno, JWT。
**Spec:** docs/superpowers/specs/2026-10-21-backend-design.md

## Global Constraints

- 500 字切块、1536 维 embedding、top 5 检索、20 MB 上传。
- 用户私有知识库，管理员会话只读及删除权限。
- 不修改原转换工具和现有用户文件，不提交整个原工作区。

## Review Focus

- 跨用户会话、附件、向量检索隔离。
- 模型失败和断线不会保存半轮消息。
- 文件解析、向量入库失败清理磁盘与事务。
- SSE 跨块中文解码、错误事件和流结束检测。
- 会话发送与删除并发的数据库锁和外键约束。
