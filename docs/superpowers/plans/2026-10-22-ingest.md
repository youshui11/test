# 导入资料 Implementation Plan

> For agentic workers: use superpowers:executing-plans task-by-task.

**Goal:** 已确认的七格式导入、语义切分、后台向量入库与状态轮询。
**Architecture:** 子进程转换器 + 异步受管任务 + 持久化任务状态 + 短入库事务，前端复用认证。
**Tech Stack:** FastAPI、SQLAlchemy async、PostgreSQL/pgvector、OpenAI SDK、Office/PDF 解析库。
**Spec:** docs/superpowers/specs/2026-10-22-ingest-design.md

## Global Constraints

- 不修改 agent/server.py，指纹基线 67c9ad253c7dcf8726508b052942b827cf11d187ed39c48dfed5968be920b45d。
- 文件 50 MB，任务临时目录 ziliao/md/，支持 pdf/docx/xlsx/xls/pptx/txt/md。
- 切分目标 200–600 字，上限 800 字，相邻块 1–2 句重叠；1536 维，每批20，限流最多重试3次。
- 保留当前用户未提交的前端样式与布局改动。

## Review Focus

- 失败/取消无部分知识片段，任务状态和清理一致。
- 任务重启恢复、并发上限和生命周期管理。
- 文件类型、解压体积、子进程输出和超时约束。
- 用户隔离、原有附件接口兼容、数据库升级不丢已有数据。
- 前端轮询卸载取消、成功/失败提示与重复提交保护。
