# 资料查询助手后端设计（已确认并实施）

## 目标和依据

依据用户提供的《Codex后端提示词.docx》，在现有 Vue 3 CDN 前端后增加可运行的 Python 后端，完成认证、对话、文件上传、RAG 和管理员查询、删除。保留现有转换工具及未提交文件。

验收标准：注册和登录后可以上传资料并提问；回答通过 SSE 返回并保存；重启服务后记录保留；普通用户不能访问他人的会话、文件或知识片段；管理员可以查看和删除会话。

## 方案选择

采用文档指定的 FastAPI + SQLAlchemy 2 异步 + asyncpg + PostgreSQL/pgvector + Agno。相比扩展当前 AgentOS 示例，该方案更直接对应前端业务接口，也便于统一认证与事务。SQLite 不作为正式存储替代品，避免与 pgvector 要求不一致。

新增 backend/，按文档分为 config、models、schemas、api、services、agent；另加数据库初始化入口、测试和 .env.example。现有根目录 server.py、agno_agent.py 保留为示例，正式入口为 backend.server:app。

## 配置与初始化

数据库默认连接到 localhost:5432/wendang，用户名为文档指定用户；凭据通过环境变量配置，样例文件说明填写方式。JWT 密钥和模型密钥通过环境变量提供，不写进源码。应用启动检查配置并关闭数据库连接池；数据库初始化通过明确命令执行，建立表、pgvector 扩展与索引，创建可配置的管理员账号，不预置公开演示密码。

LLM 与 embedding 分别配置模型、密钥和 API 地址；embedding 默认使用 1536 维，与文档表结构一致。Agno 使用配置的聊天模型，支持 OpenAI 兼容服务。缺少密钥时返回明确配置错误，不生成模拟回答。

## 数据与权限

保留文档中的 users、sessions、messages、knowledge_base，并增加 uploads 表记录文件归属、磁盘路径、大小和入库状态。knowledge_base 关联上传记录，支持按所有者过滤检索；文件默认作为用户私有知识库。

用户名唯一，密码仅保存哈希。JWT 包含用户标识和过期时间，每次请求查验用户和角色。注册只能生成普通用户。普通用户仅能读写自己的会话与附件；管理员可读取所有会话，删除会话时级联删除消息。上传资料独立于会话存在，删除会话不删除用户知识库。

## HTTP 与前端对接

实现文档列出的登录、会话列表、新建、消息列表、发送消息、上传、管理员列表和删除接口。补充现有前端需要的 POST /api/users 注册接口、鉴权文件下载接口及健康检查。

字段继续使用 sessionId、msgId、fileId、fileName、updateTime 等现有命名。统一错误响应，明确区分未登录、无权限、未找到、输入错误和上游服务错误。CORS 来源通过配置列出，不与任意来源凭据模式混用。

将 api.js 内存 mock 改成 fetch 适配层；默认由 FastAPI 提供现有前端静态文件，通过同源 /api 请求。静态路由只公开前端需要的文件，不公开项目目录、环境文件或上传目录。移除页面中“数据刷新重置”和固定演示账号文案。

POST 消息接口使用 fetch 读取 SSE，事件约定为 delta（文本增量）、done（完整消息）、error（失败信息）。适配层保留 Promise 返回约定，并支持可选增量回调；聊天页面在收到增量时更新临时 AI 消息，完成后重新加载已保存记录。处理跨网络块事件、UTF-8 中文及失败清理。

## 上传与 RAG

第一版支持当前项目已有解析能力的 PDF、DOCX，以及 TXT、Markdown。限制单文件 20 MB，拒绝不支持的格式、空文件及无可提取文本的扫描 PDF；不执行文件中的代码。使用随机磁盘名称，原文件名仅作为展示信息，避免路径穿越。

文件提取文本后按 500 字切块，调用 embedding API 批量向量化，校验维度后事务写入 uploads 与 knowledge_base。失败时回滚并清理临时文件。同步提取和文件操作移出异步事件循环。

提问时向量化问题，以余弦距离检索当前用户知识库前 5 块；提供 fileIds 时收窄至指定且属于该用户的文件。将命中文本标为参考资料，提示智能体将资料中的指令视为数据。组装有限的历史消息和参考片段，交由 Agno 流式生成。

同一会话避免并发生成造成历史错乱；生成期间不持有长数据库事务。仅在生成成功后原子保存用户消息及 AI 消息、更新时间和首问标题；失败或客户端断开不保存半轮对话。数据库约束和锁保证删除与发送交错时不产生孤立消息。
