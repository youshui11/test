# 全文输出遗漏修复验收

2026-10-22：用户提问 `09_外观检测相机与追溯接入.pdf中全部内容`，反馈缺少第 3–5 章。

根因：普通向量检索固定只返回相关度最高的 5 个片段，全文请求也沿用该路径，模型无法看到该文件的全部 8 个片段。

修复：明确索取指定文件全文时，通过当前用户和精确文件名（或附件 ID）过滤，按 chunk_index、id 顺序取全部片段并直接流式返回。普通问答保留向量检索。缺少范围、文件不存在、同名多份或全文过长时明确报错，避免返回不完整或错误资料。未改动 agent/server.py。

验证：50 项 Python 测试、9 项 JavaScript 测试通过。新增回归覆盖超过 5 个章节、章节顺序、用户与文件隔离、未知文件、超长内容及通过附件指定范围。真实 PostgreSQL 只读核对目标 PDF 的 8 个片段：输出全部 8 个、逐一匹配、顺序正确，回复 1809 字符；未调用模型或 embedding，未改动原有资料。已重启后端。
