# 停用聊天预检索与替代验证

聊天接口仅把真实历史和当前问题传给回答服务，不执行预检索、不注入参考资料 JSON。CX、QWJS 在 `knowledge_scope` 中获得当前登录身份、数据库会话工厂、附件范围及独立 embedding 服务。上传和 DR 导入保持原流程。

普通附件文字提取与固定 500 字切分已迁移到 `agent/tools/attachments.py`，向量校验直接从 `agent/embedding.py` 导入。原检索模块、聊天预检索注册、回滚配置开关、参考资料参数与注入分支均已删除。

新增 `backend/tests/test_chat_routing.py` 验证：

- 将 embedding 替换为报错函数，问候及聊天历史回顾仍正常完成；传入模型的消息严格等于真实历史和当前问题，没有附加参考资料 JSON。
- 在相同报错替身下，通过真实聊天接口调用 QWJS，按顺序完整返回数据库正文，证明身份和数据库上下文继续传递。

已有 CX PostgreSQL 检索、QWJS 全文/歧义/过长/身份及附件范围测试继续验证替代工具。旧预检索全文与回滚测试已移除；PostgreSQL 中的向量排序、共享查询和文件范围检查改为调用真实 CX 工具，其他事务和锁检查保留。`test_attachments.py` 验证 UTF-8/BOM、固定切分，以及 TXT、Markdown、Word、PDF 的真实上传、向量入库和原件下载；已有失败清理、取消和下载权限测试继续保留。

模型边界使用确定性替身，不发送用户资料给外部模型；工具查询、API、数据库及流式处理执行真实代码，未声称验证实际模型每次都会遵循委派指令。

`agent/serve.py`、`agent/server.py` 均受保护，本次不作修改。下次启动项目后生效，不需要数据库迁移或重新生成向量。
